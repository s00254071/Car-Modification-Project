# Car Tuner

A Windows desktop app where you build your own tuned car. Pick parts, watch your top speed and cost go up, and save your build.

Made in C# with WPF.

## Features

- 18 car parts across 9 categories (engine, turbo, exhaust, wheels and more)
- Picture preview of each part and your full build
- Live top speed (starts at 230 km/h) and total cost
- Save and load builds as `.json` files
- Sound effects with an on/off button

## How it works

- **Workshop:** add or remove parts
- **Garage:** load and view saved builds
- Only one part per category, so a new engine replaces the old one

## Built with

C#, WPF, .NET Framework 4.7.2, Visual Studio

## Run it

1. Download the repo.
2. Open `CarTuner.csproj` in Visual Studio (Windows only).
3. Press **F5**.
